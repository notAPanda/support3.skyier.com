# Praca z AI

## Budowanie stron za pomocą AI

To jest nasz proponowany flow do pracy z różnymi LLM'ami.
Przedstawione prompty można dowolnie modyfikować.


Prompt do tworzenia strony sprzedażowej lub Landing page:

```html
Jesteś wysokiej klasy developerem ui/ux.
Stwórz stronę sprzedażową (HTML, CSS, Javascript).

Kod, który stworzysz będzie umieszczony wewnątrz gotowej strony, która:
- ma już górne menu oraz stopkę,
- jest zbudowana na frameworku css Bootstrap 5

Kolorystyka strony: (tutaj Twój opis kolorystyki)

Linki jakich powinieneś użyć:
- link do checkoutu - (tutaj Twój link do checkoutu)

Treści na stronie: (tutaj Twój opis strony sprzedażowej)

Grafiki jakich możesz użyć:
- (link do obrazka) - (opis obrazka jak można go użyć) (ewentualne wymiary, wskazanie czy grafika pionowa/pozioma)

```

Jeśli nie masz wszystkich informacji do tego prompta - oczywiście możesz go modyfikować pod swoje wymagania.
Obrazki możesz wgrać do osobnego landing page w Skyier -> wydobyć linki tych obrazków (prawy przycisk - kopiuj link grafiki) -> kazać czatowi użyć tych obrazków w formie podobnej do tego co zaproponowaliśmy.
